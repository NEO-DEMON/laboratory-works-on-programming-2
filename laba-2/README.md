## Цель работы
Изучение основ модульного тестирования в Python с использованием библиотеки `unittest`.

## Задание
Написать функцию `add(nums, target)`, которая принимает массив целых чисел `nums` и целое число `target`, и возвращает индексы двух элементов массива, в сумме дающих `target`. Если решения нет, функция возвращает пустой список `[]`.

## Описание реализации
Для решения задачи использован метод полного перебора (brute-force) с помощью двух вложенных циклов:
1. Внешний цикл перебирает элементы с индексами `i`.
2. Внутренний цикл перебирает элементы с индексами `j` (начиная с `i + 1`).
3. Если сумма `nums[i] + nums[j]` равна `target`, возвращается список `[i, j]`.
4. Если после завершения циклов решение не найдено, возвращается `[]`.

**Сложность алгоритма:** O(n²) по времени, O(1) по памяти.

## Тестирование
Тестирование проводилось с использованием фреймворка `unittest` в файле `test_lab.py`. 

Были реализованы следующие тест-кейсы:
1. **Тест 1:** Обычный случай. `nums = [2, 7, 11, 15], target = 9`. Ожидаемый результат: `[0, 1]`.
2. **Тест 2:** Числа не по порядку. `nums = [3, 2, 4], target = 6`. Ожидаемый результат: `[1, 2]`.
3. **Тест 3:** Одинаковые числа. `nums = [3, 3], target = 6`. Ожидаемый результат: `[0, 1]`.
4. **Тест 4:** Отсутствие решения. `nums = [1, 2, 3], target = 10`. Ожидаемый результат: `[]`.

## Результат
Все 4 теста успешно пройдены (`OK`).
